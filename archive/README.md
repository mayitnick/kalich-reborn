# 📦 Архив PWA (Progressive Web App)

В этой директории законсервирован исходный код PWA-фронтенда:
- `pwa/`: HTML, стили, JavaScript-клиент (`app.js`), Service Worker (`sw.js`), манифест и иконки.
- `Dockerfile.frontend`: Конфигурация Nginx контейнера для раздачи статических файлов.

Фронтенд временно выведен из активной разработки и заархивирован для облегчения поддержки и фокуса на основном функционале бота и REST API.
При необходимости восстановления PWA файлы могут быть перемещены обратно в корень проекта.
