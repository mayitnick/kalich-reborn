# Kalich Bot 🦊

Калич — пушистый лисёнок-помощник, который помогает отслеживать расписание занятий, находить нужные кабинеты и мгновенно оповещает о любых изменениях! 

## Особенности
- 🚀 **Быстрые ответы**: Использование in-memory кеширования расписания для моментального доступа.
- 🧑‍🏫 **Роли**: Поддержка как студентов, так и преподавателей.
- ⚙️ **Настройки**: Удобное меню `/settings` для управления уведомлениями и голосовыми сообщениями.
- 🦊 **Дружелюбный интерфейс**: Обильное использование эмодзи и теплых фраз в ответах.

## Запуск
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Создайте файл `.env` на основе `.env.example` и укажите там ваш `BOT_TOKEN`, `MODERATOR_ID` и `LOG_GROUP_ID`.
4. Запустите бота: `python kalich.py`.

## Структура БД
Для хранения данных используется SQLite (`schedules.db`). При первом запуске бот автоматически создаст все необходимые таблицы:
- `user_settings` (пользовательские настройки)
- `teachers` (заявки преподавателей)
- `schedules` (кеш на текущую неделю)
- `schedule_history` (история)
