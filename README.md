**Kalich Reborn** — современная цифровая экосистема для студентов и преподавателей колледжа, объединяющая многофункционального Telegram-бота и быстрый REST API сервер. Проект создан для того, чтобы навсегда избавить студентов от путаницы со звонками, ручных поисков на сайте и внезапных замен аудиторий.

> [!TIP]
> 🦊 **Пушистая забота в каждой строчке**: бот не просто отдаёт расписание, а понимает контекст — считает оставшееся время до конца пары, подсказывает совмещённые занятия, строит аналитические графики и бережно будит утром!

## <a id="features"></a>✨ Ключевые возможности

### 📅 Динамический парсинг (Глорис)
* ⚡ **Без жесткого хардкода**: автоматический сбор актуального реестра групп со всех отделений колледжа (`глорис-окту-*.рф`).
* 🔍 **Умный нечёткий поиск (`find_group_info`)**: бот понимает запросы с дефисами, пробелами и разным регистром («ис 21 25», «ИС-21-25», «ис2125») и динамически подгружает новые группы.
* 🛡️ **Многоуровневое кэширование**: проверка MD5-хешей для мгновенного определения изменений и долгосрочный архив расписания по датам в SQLite.

### 🔔 Уведомления и замены
* 🔄 **Точечные оповещения**: при изменении расписания оповещаются только подписанные студенты конкретных групп.
* ☀️ **Утренний дайджест**: персональная сводка на день в 07:00 по будням.
* 👥 **Анализ совмещений**: бот сопоставляет параллельные потоки и выделяет совмещённые пары (`+совм. с ...`).

### 🧑‍🏫 Панель преподавателя
* 🚪 **Привязка кабинетов**: автоматический сбор единого расписания преподавателя по закреплённым за ним аудиториям.
* ✏️ **Мгновенные замены (`/move`)**: смена предмета или аудитории прямо из Telegram с защитой от случайных ошибок (5 минут на отмену) и автоуведомлением студентов.
* 🛡️ **Верификация**: строгая модерация преподавательских аккаунтов администратором.

### 📊 Графическая аналитика
* 🥧 **Круговые диаграммы предметов (`/stats`)**: визуализация структуры семестра и баланса нагрузки.
* 📈 **Графики занятости**: распределение пар по дням недели и анализ самых загруженных кабинетов через headless Matplotlib.

### ⚡ Надёжность и быстродействие
* 🚀 **SQLite WAL Mode**: неблокирующее параллельное чтение и запись (`PRAGMA journal_mode=WAL;` и `busy_timeout=5000`).
* 🩺 **Health Check API**: готовый эндпоинт `/api/health` для автоматического мониторинга живости базы данных и сервисов.

## <a id="architecture"></a>🏗️ Архитектура

```
                            ┌───────────────────────────────┐
                            │   Сайт колледжа (Глорис)      │
                            │   Отделения 1, 2, 3           │
                            └───────────────┬───────────────┘
                                            │ HTTPS (Requests / No Proxy)
                                            ▼
 ┌─────────────────────────┐     ┌──────────────────────────┐
 │      Telegram Bot       │     │        REST API          │
 │       (kalich.py)       │     │     (api_server.py)      │
 │  pyTelegramBotAPI + DI  │     │      aiohttp :8999       │
 └────────────┬────────────┘     └────────────┬─────────────┘
              │                               │
              ▼                               ▼
        ┌───────────────────────────────────────────┐
        │             SQLite База данных            │
        │   schedules.db (WAL mode, busy_timeout)   │
        │  • schedules         • schedule_history   │
        │  • teachers          • item_stickers      │
        │  • overrides         • user_settings      │
        └───────────────────────────────────────────┘
```

```text
src/
├── core/         # DI-контейнер (ServiceContainer), контекст (AppContext) и автосканер команд
├── services/     # Бизнес-логика: парсер (parser.py), нотификатор (notifier.py), аналитика (analytics.py)
├── database.py   # Слой доступа к SQLite (WAL, транзакции, менеджеры подписок)
├── config.py     # Конфигурация, переменные окружения и расписание звонков
└── bot/          # Обработчики сообщений, клавиатуры и команды
```

## <a id="commands"></a>🤖 Команды Telegram-бота

### 🎓 Для студентов
| Команда | Описание |
|:---|:---|
| `/r` | Расписание на сегодня для своей группы |
| `/db [день/дата]` | Расписание на выбранный день (`/db вт`) или конкретную дату (`/db 16.09.2026`) |
| `/w [группа]` | Быстрый просмотр расписания любой группы колледжа без переключения подписки |
| `/now` | Текущая пара, кабинет, преподаватель и прогресс-бар оставшегося времени |
| `/next` | Следующая пара и точный таймер до её начала |
| `/time` | Расписание звонков и таймер до перемены |
| `/stats` | Инфографика учебной нагрузки и диаграмма предметов |
| `/unsub` | Отписка от группы или сброс выбранного отделения |
| `/settings` | Персональные настройки (уведомления, эффекты, пушистый режим 🦊) |
| `/cancel` | Отмена текущего многошагового ввода |

### 🧑‍🏫 Для преподавателей
| Команда | Описание |
|:---|:---|
| `/r` | Личное расписание на сегодня по всем привязанным аудиториям |
| `/db [день]` | Расписание занятий на любой день недели |
| `/move [день] [пара] [кабинет] [п=Предмет] [группа]` | Создание замены с 5-минутным окном отмены |
| `/cancel_move [id]` | Быстрая отмена зарегистрированной замены |
| `/list` | Карточка преподавателя: список закреплённых аудиторий и статус |

### 🛡️ Для администраторов
| Команда | Описание |
|:---|:---|
| `/fill` | Пакетное предзаполнение базы данных расписанием на всю неделю |
| `/flush` | Экстренная очистка кэша текущей недели |
| `/broadcast [текст]` | Информационное оповещение всех пользователей |

## <a id="quickstart"></a>🚀 Быстрый старт

### Требования
- **Python 3.11+**
- Токен бота от [@BotFather](https://t.me/BotFather)

### 1. Клонирование репозитория
```bash
git clone https://github.com/mayitnick/kalich-reborn.git
cd kalich-reborn
```

### 2. Установка зависимостей
```bash
# Создание виртуального окружения
python -m venv venv

# Активация:
# Windows (PowerShell):
venv\Scripts\Activate.ps1
# Linux / macOS:
source venv/bin/activate

# Установка пакетов
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Конфигурация (`.env`)
Создайте файл конфигурации:
```bash
cp .env.example .env
```
И укажите базовые параметры:
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOprstUVWXYZ       # Токен вашего Telegram-бота
MODERATOR_ID=123456789                              # Ваш Telegram ID для админ-прав
LOG_GROUP_ID=-1001234567890                         # (Опционально) ID группы для логов
PWA_PORT=8999                                       # Порт REST API сервера
```

### 4. Запуск
```bash
# Запуск Telegram-бота
python kalich.py

# В отдельном терминале: запуск REST API сервера
python api_server.py
```

## <a id="docker"></a>🐳 Запуск через Docker

Разверните весь стек одной командой с сохранением данных:

```bash
docker compose up -d --build
```

- Контейнер `kalich_backend` автоматически поднимает бота и сервер на порту `8999`.
- Данные SQLite и кэши монтируются в локальную директорию `./data`.

## <a id="api"></a>🔌 REST API Reference

Базовый URL: `http://localhost:8999`

| Метод | Эндпоинт | Назначение |
|:---|:---|:---|
| `GET` | `/api/health` | Мониторинг состояния сервисов, парсера и SQLite |
| `GET` | `/api/groups` | Список всех распознанных учебных групп |
| `GET` | `/api/schedule` | Расписание группы по параметрам `department`, `group_id`, `day` |
| `GET` | `/api/teacher/schedule` | Расписание преподавателя по аудиториям |
| `POST` | `/api/auth` | Авторизация клиента / устройства |
| `POST` | `/api/override` | Регистрация замены аудитории или предмета |
| `GET` | `/api/analytics` | Данные аналитики и статистики нагрузки |
